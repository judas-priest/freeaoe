## Phase 1: Critical Blockers (must fix to even play)

### Task 1: Single SDL window lifecycle

**Problem:** ScenarioBrowser creates SdlWindow, then Engine creates another. Android SDL2 allows only one.

**Root cause:** `ScenarioBrowser::run()` creates `std::make_unique<SdlWindow>()`, destroys it, then `Engine::setup()` creates another one. SDL on Android can't handle this.

**Fix:** Don't create a separate window. Refactor so ScenarioBrowser renders into Engine's window.

**Files:**
- Modify: `src/main.cpp` — restructure startup flow
- Modify: `src/Engine.h` — expose window creation separately from game setup
- Modify: `src/Engine.cpp` — split setup() into createWindow() + setupGame(scenario)
- Modify: `src/ui/ScenarioBrowser.h` — take SdlWindow* instead of creating own
- Modify: `src/ui/ScenarioBrowser.cpp` — remove window creation, use passed window

### Task 2: Fix terrain PNG rendering

**Problem:** PNG terrain textures are found but map is black. `m_tileSquareCount` is 0 for PNG terrain (only set from SLP frame count). MapRenderer uses `m_tileSquareCount` for tile frame selection.

**Root cause chain:**
1. `TerrainSprite` constructor: PNG found, `m_isPng = true`, but `m_tileSquareCount = sqrt(m_slp->getFrameCount())` only runs for SLP path (line 101)
2. For PNG terrain, `m_tileSquareCount` stays at 0
3. In `MapRenderer::updateTexture()`, terrain is fetched but tile rendering fails because frame index calculation uses `m_tileSquareCount`
4. The PNG rendering path in `TerrainSprite` uses `data->TerrainDimensions` (already logged as "10 10") but `m_tileSquareCount` must also be set

**Files:**
- Modify: `src/resource/TerrainSprite.cpp:56-101` — set m_tileSquareCount for PNG path
- Modify: `src/resource/TerrainSprite.cpp` — ensure PNG drawTile/blend work correctly

```cpp
m_isPng = true;
m_tileSquareCount = data->TerrainDimensions.first; // Usually 10 for HD terrain
```

- [ ] **Step 2: Verify PNG drawTile implementation**

- [ ] **Step 2: Add language-specific campaign path**

In `AssetManager_HD::campaignsPath()`, try language-specific path first:
```cpp
std::string AssetManager_HD::campaignsPath() const {
    const std::string language = Config::Inst().getValue(Config::Language);
    if (language != "en") {
        // Try language-specific campaigns first
        std::string langPath = genie::util::resolvePathCaseInsensitive(
            "/campaign/", m_gamePath + "/resources/" + language);
        if (std::filesystem::exists(langPath)) {
            return langPath;
        }
    }
    // Fall back to HD retail-campaigns, then classic
    std::string hdPath = genie::util::resolvePathCaseInsensitive("/drs/retail-campaigns/", m_hdAssetPath);
    if (std::filesystem::exists(hdPath)) return hdPath;
    return genie::util::resolvePathCaseInsensitive("/campaign/", m_hdAssetPath);
}
```
