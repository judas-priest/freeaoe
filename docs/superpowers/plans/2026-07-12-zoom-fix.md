# Pinch-Zoom Fix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix pinch-zoom bug where map stays in place but units slide away during zoom.

**Architecture:** The zoom is applied twice: once via `Camera::setViewportSize` (shifting the coordinate center) and once via `SDL_RenderCopy` center-crop (visual zoom). The crop center (texW/2, texH/2) doesn't match the camera center (viewportW/2, viewportH/2), so units drift. Fix: remove `setViewportSize` from zoom — let the camera stay at full viewport, use only the SDL_RenderCopy crop for visual zoom.

**Tech Stack:** C++20, SDL2

**Verified against:**
- [SDL Wiki: SDL_RenderSetScale](https://wiki.libsdl.org/SDL2/SDL_RenderSetScale) — alternative approach (scale all draw ops), not used here to minimize changes
- [GameDev.net: SDL2 Zoom](https://gamedev.net/forums/topic/685677-sdl-2-zooming-in-and-out/5329367/) — texture crop is valid if coordinates are consistent

### Task 1: Remove setViewportSize from pinch-zoom handler

The camera viewport must stay at `m_baseViewportSize` during zoom. The SDL_RenderCopy center-crop alone provides the visual zoom effect. `Camera::absoluteScreenPos()` will use the full viewport center, matching the crop center.

**Files:**
- Modify: `src/Engine.cpp:590-595`
