# Plan: In-Game Chat UI

**Goal:** Enter key opens a chat input box. SDL_StartTextInput accumulates characters, Enter sends via `EventManager::sendChatMessage`. Make `Engine` an `EventListener` to receive `onChatMessage` and push to `m_visibleText[]`. If the message is a number 1–42, play the corresponding taunt WAV.

**Status:** Not started

---

## Overview

`EventManager::sendChatMessage` and `EventListener::onChatMessage` already exist (EventManager.h line 100, EventListener.h line 100). We need:

1. Chat input widget state in `Engine`
2. Key handling to open/close the input
3. SDL text input events to accumulate the string
4. Send on Enter, dismiss on Escape
5. Display incoming messages in `m_visibleText`
6. Taunt playback for messages "1"–"42"

## Step 3: `onChatMessage` implementation

```cpp
void Engine::onChatMessage(const int sourcePlayer, const int /*targetPlayer*/,
                            const std::string &message)
{
    // Build display string: "Player N: message"
    std::string display = "Player " + std::to_string(sourcePlayer) + ": " + message;
    addMessage(display);

    // Taunt: if message is a number 1–42, play taunt WAV
    try {
        int n = std::stoi(message);
        if (n >= 1 && n <= 42) {
            playTaunt(n);
        }
    } catch (...) {
        // Not a number — ignore
    }
}
```

## Step 4: `playTaunt()` helper

Taunts are WAV files stored in `resources/taunts/` named `taunt1.wav` through `taunt42.wav`.

```cpp
void Engine::playTaunt(int n)
{
    // Taunts are in the game's audio directory
    const std::string path = Config::Inst().gamePath + "/resources/_common/taunts/xo"
                             + std::to_string(n) + ".wav";
    // Use the existing audio player
    AudioPlayer::Inst().playFile(path);
}
```

Check exact path by looking at existing WAV playback in `ScenarioController` for sound effects — the `Sound` trigger effect calls `AudioPlayer`. The taunt path may vary; use the scn file's trigger audio path as a reference.

## Step 5: Key handling — open/close chat

In `Engine::handleKeyEvent`:

```cpp
case SDLK_RETURN:
case SDLK_KP_ENTER:
    if (m_chat.active) {
        // Send the message
        if (!m_chat.buffer.empty()) {
            EventManager::sendChatMessage(
                state->humanPlayer()->playerId, -1, m_chat.buffer);
        }
        m_chat.buffer.clear();
        m_chat.active = false;
        SDL_StopTextInput();
        return true;
    } else {
        // Open chat
        m_chat.active = true;
        m_chat.buffer.clear();
        SDL_StartTextInput();
        return true;
    }

case SDLK_ESCAPE:
    if (m_chat.active) {
        m_chat.active = false;
        m_chat.buffer.clear();
        SDL_StopTextInput();
        return true;
    }
    break;

case SDLK_BACKSPACE:
    if (m_chat.active && !m_chat.buffer.empty()) {
        m_chat.buffer.pop_back();
        return true;
    }
    break;
```

## Step 7: Draw the chat input

In `Engine::drawUi()`, when `m_chat.active`:

```cpp
if (m_chat.active) {
    // Draw semi-transparent dark bar at bottom of game area
    Drawable::Rect chatBg;
    chatBg.rect = ScreenRect(0, m_gameAreaHeight - 30, renderTarget_->getSize().width, 30);
    chatBg.fillColor = Drawable::Color(0, 0, 0, 180);
    renderTarget_->draw(chatBg);

    // Draw input text + cursor
    std::string display = "Say: " + m_chat.buffer + "_";
    if (!m_chat.inputText) {
        m_chat.inputText = renderTarget_->createText(display, 16);
    } else {
        m_chat.inputText->text = display;
    }
    renderTarget_->draw(*m_chat.inputText, ScreenPos(8, m_gameAreaHeight - 26));
}
```
