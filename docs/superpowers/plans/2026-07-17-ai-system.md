# AI System Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Complete AI -- .per file loading from scenarios, defensive reactions, strategic variety (rush/boom/turtle), garrison use, monk conversion, wall building, naval, market trading, and diplomacy changes.

**Architecture:**

The AI system has two layers that run in parallel every tick (in `GameState::update`):

1. **BasicAI** (`src/ai/BasicAI.h/.cpp`) -- Hardcoded C++ AI with 11 behaviors: scout, train villagers, build houses/barracks/archery/stable/siege/drop-off sites, research loom/techs, advance age, train military, attack with army. Controlled by `DifficultyParams` (villager cap, military cap, attack threshold, update interval, gather bonus). Does NOT react to attacks, does NOT garrison, does NOT build walls/docks, does NOT use monks/market.

2. **AiScript** (`src/ai/AiScript.h/.cpp`) -- Rule-based system loaded via `ScriptLoader::parse()` from .per files. Has full parser (flex/bison in `grammar.gen.tab.cpp`, `lex.yy.cc`). Rules are `AiRule` objects with conditions + actions. Many conditions/actions ARE implemented (resource checks, unit counts, train, build, research, buy/sell commodity, escrow, timers, goals, strategic numbers). But `ScriptLoader::parse()` is NEVER called from `GameState` -- the `m_aiScript` is created empty.

3. **AiPlayer** (`src/ai/AiPlayer.h/.cpp`) -- Extends `Player` with `m_basicAI`, `m_aiScript`, difficulty params, escrow reserves. Created in `GameState` lines ~312 and ~466.

Key data structures:
- `genie::ScnMainPlayerData::aiFiles[16]` -- contains `.aiFilename` and `.perFile` (the actual script text) for each player
- `genie::ScnMainPlayerData::personalityNames[16]` -- AI personality names
- `genie::ScnFile::includedFiles` -- vector of `ScnPersonalityScript` with `.filename` and `.content`
- `DiplomaticStance` enum: `Ally`, `Neutral`, `Enemy` (in `ai/gen/enums.h`)
- `Player::m_diplomaticStances` -- vector of stance per player
- `ActionGarrison` -- garrison action already exists in `src/actions/ActionGarrison.h/.cpp`

**Tech Stack:** C++20, SDL2

void AiPlayer::reportThreat(const MapPos &pos, int attackerPlayerId, Time time)
{
    // Merge with existing threat if close enough
    const float mergeDistance = Constants::TILE_SIZE * 8;
    for (auto &threat : m_activeThreats) {
        float dx = threat.location.x - pos.x;
        float dy = threat.location.y - pos.y;
        if (dx * dx + dy * dy < mergeDistance * mergeDistance) {
            threat.lastSeen = time;
            threat.severity++;
            return;
        }
    }
    m_activeThreats.push_back({pos, time, attackerPlayerId, 1});
}

void AiPlayer::clearStaleThreats(Time time)
{
    std::erase_if(m_activeThreats, [time](const ThreatInfo &t) {
        return (time - t.lastSeen) > 30000; // 30 seconds stale
    });
}

void BasicAI::defendAgainstThreats()
{
    m_player->clearStaleThreats(m_lastUpdate);
    if (m_player->m_activeThreats.empty()) return;

    // Respond to the most severe threat
    const AiPlayer::ThreatInfo *worst = nullptr;
    for (const auto &threat : m_player->m_activeThreats) {
        if (!worst || threat.severity > worst->severity) {
            worst = &threat;
        }
    }
    if (!worst) return;

    // Send up to 5 nearby idle military to defend
    int sent = 0;
    for (const Unit::Ptr &unit : m_unitManager->units()) {
        if (!unit || unit->playerId() != m_player->playerId) continue;
        if (!isMilitaryUnit(unit->data()->ID)) continue;
        if (unit->actions.currentAction()) continue; // busy

        float dist = std::abs(unit->position().x - worst->location.x) +
                     std::abs(unit->position().y - worst->location.y);
        if (dist > Constants::TILE_SIZE * 40) continue; // too far

        unit->actions.setCurrentAction(ActionMove::moveUnitTo(unit, worst->location));
        if (++sent >= 5) break;
    }
}
```

    // Only garrison if threat is near the TC
    MapPos tcPos;
    Unit::Ptr tc;
    for (const Unit::Ptr &unit : m_unitManager->units()) {

            tcPos = unit->position();
            tc = unit;
            break;

    if (!tc) return;

            break;

    if (!threatNearTC) return;

    // Garrison idle villagers into TC

        if (!unit || unit->playerId() != m_player->playerId) continue;

void BasicAI::useMonksOffensively()
{
    for (const Unit::Ptr &monk : m_unitManager->units()) {
        if (!monk || monk->playerId() != m_player->playerId) continue;
        if (monk->data()->ID != 125) continue; // Monk
        if (monk->actions.currentAction()) continue; // Busy

        // Find nearest enemy unit to convert (prefer expensive units)
        Unit::Ptr bestTarget;
        float bestScore = -1;

        for (const Unit::Ptr &enemy : m_unitManager->units()) {
            if (!enemy || enemy->isDead() || enemy->isDying()) continue;
            if (enemy->playerId() == m_player->playerId || enemy->playerId() == 0) continue;

            float dist = monk->distanceTo(enemy);
            if (dist > Constants::TILE_SIZE * 12) continue; // Conversion range ~10 tiles

            // Score: prefer knights, siege, expensive units
            float score = 1.0f;
            if (isMilitaryUnit(enemy->data()->ID)) score += 5.0f;
            if (enemy->data()->ID == 38 || enemy->data()->ID == 283 || enemy->data()->ID == 569) score += 10.0f; // Knights
            score -= dist / (Constants::TILE_SIZE * 5); // Closer is better

            if (score > bestScore) {
                bestScore = score;
                bestTarget = enemy;
            }
        }

        if (bestTarget) {
            Task task = monk->actions.findTaskWithTarget(bestTarget);
            if (task.isValid()) {
                IAction::assignTask(task, monk, IAction::AssignType::Replace);
            }
        }
    }
}
```

bool BasicAI::isWaterMap() const
{
    // Check if there's significant water on the map by looking for fish or water tiles
    int fishCount = 0;
    for (const Unit::Ptr &unit : m_unitManager->units()) {
        if (!unit) continue;
        // Fish classes: deep sea fish, shore fish
        if (unit->data()->Class == genie::Unit::OceanFish ||
            unit->data()->Class == genie::Unit::ShoreFish) {
            fishCount++;
        }
    }
    return fishCount >= 3;
}

void BasicAI::buildWalls()
{
    // Only build walls in Feudal Age+ and if we have enough wood
    if (m_player->currentAge() < Player::FeudalAge) return;

    float wood = m_player->resourcesAvailable(genie::ResourceType::WoodStorage);
    if (wood < 50) return; // Need wood buffer

    // Turtle strategy builds walls early, others build late
    if (m_strategy != Strategy::Turtle && m_player->currentAge() < Player::CastleAge) return;

    // Limit total wall segments
    if (countBuildingsOfType(72) >= 30) return; // Palisade Wall = 72

    // Find TC position
    MapPos tcPos;
    bool foundTC = false;
    for (const Unit::Ptr &unit : m_unitManager->units()) {
        if (unit && unit->playerId() == m_player->playerId && unit->data()->ID == 109) {
            tcPos = unit->position();
            foundTC = true;
            break;
        }
    }
    if (!foundTC) return;

    // Build wall segments in a rough circle around TC at radius ~8 tiles
    float radius = Constants::TILE_SIZE * 8;
    int wallsBuilt = countBuildingsOfType(72);
    int segments = 12; // 12 segments around the perimeter
    float angleStep = 2.0f * M_PI / segments;
    float angle = wallsBuilt * angleStep; // Build next segment

    if (wallsBuilt >= segments) return; // Perimeter complete

    MapPos wallPos(tcPos.x + cos(angle) * radius, tcPos.y + sin(angle) * radius);

    // Bounds check
    if (wallPos.x < Constants::TILE_SIZE * 3 || wallPos.y < Constants::TILE_SIZE * 3) return;
    if (wallPos.x >= m_unitManager->map()->pixelWidth() - Constants::TILE_SIZE * 3) return;
    if (wallPos.y >= m_unitManager->map()->pixelHeight() - Constants::TILE_SIZE * 3) return;

    // Place palisade wall (72, 2W per segment)
    if (wood >= 2) {
        buildStructure(72, 2);
    }
}
